WHY THIS PAGE EXISTS

The main console demonstrates RCAI's operational workflow. This page evaluates whether the Bayesian active investigation approach performs reliably against baseline methods under reproducible, frozen benchmark conditions.

WHAT IS PRECOMPUTED?

The displayed results load instantly from the latest completed evaluation run stored in the repository artifact store (docs/results/). Reviewers do not need to wait for multi-minute benchmark re-runs to inspect results.

WHAT DOES RE-RUN DO?

Clicking RE-RUN BENCHMARK re-executes the benchmark runner against the active microservice cluster for all 4 methods and 4 ablation variants, capturing live telemetry and refreshing the display.
